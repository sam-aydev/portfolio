## 🏗 Architectural Highlights

This portfolio moves beyond standard web templates by implementing advanced UI/UX patterns and serverless infrastructure:

* **Server Component Foundation:** Built on Next.js App Router, leveraging Server Components for core layout and SEO optimization, while isolating heavy animations to specific client boundaries.
* **Hardware-Accelerated Physics:** Utilizes `framer-motion` for complex spring-physics animations, including staggered text reveals and interactive hover states.
* **The "Engine Room" Infinite Marquee:** A mathematically stable, continuously looping tech stack presentation using native CSS masking and seamless array duplication.
* **Interactive Architecture Labs:** A custom-built split-screen interface detailing Architectural Decision Records (ADRs) with Framer Motion `AnimatePresence` for smooth state transitions.
* **Sticky Card Deck:** A highly responsive, Z-index stacked card UI for featured projects using native CSS `sticky` positioning for maximum mobile performance.
* **Serverless Email Microservice:** A custom-built Next.js API route (`/api/contact`) utilizing Nodemailer and Gmail SMTP to handle form submissions without relying on third-party quotas.
